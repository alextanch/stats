## Как сдавать работу

1. Сохраните копию ноутбука на свой Диск («Файл → Сохранить копию на Диске»).
2. Решите задания в своей копии.
3. Перед отправкой выберите «Среда выполнения → Перезапустить и выполнить всё» и убедитесь, что выводы всех ячеек (числа, графики) видны.
4. В конце ноутбука напишите 2–3 предложения вывода по практической части.
5. Откройте доступ: «Поделиться → Все, у кого есть ссылка → Читатель».
6. Пришлите преподавателю ссылку на свою копию.

Без открытого доступа преподаватель не сможет посмотреть решение.
