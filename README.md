# Лабораторные работы по математической статистике

Материалы для преподавателей: формулировки теоретических вопросов и практических задач для студентов магистратуры.
Студенты решают лабораторные в Google Colab и присылают преподавателю ссылки на свои ноутбуки.

## Окружение для подготовки лабораторных

Нужен [uv](https://docs.astral.sh/uv/getting-started/installation/).

```bash
uv sync --group dev
uv run jupyter lab
```

Окружение нужно только для того, чтобы написать и проверить задания. Студентам ничего ставить не нужно.

## Совместимость с Google Colab

Ноутбуки должны работать в Colab «из коробки»: там уже есть `numpy`, `pandas`, `scipy`,
`matplotlib`, `seaborn`, `statsmodels`, `tqdm`. Если задание требует другой пакет, добавьте
в начало ноутбука ячейку `!pip install ...`.

Версии библиотек в Colab могут отличаться от локальных. Перед публикацией прогоните
ноутбук в Colab с чистой среды («Среда выполнения → Перезапустить и выполнить всё»).

## Сдача работ

Добавляйте в каждую лабораторную такую инструкцию для студентов:

> 1. Откройте ноутбук в Google Colab и сохраните копию на свой Диск («Файл → Сохранить копию на Диске»).
> 2. Решите задания в своей копии.
> 3. Откройте доступ: «Поделиться → Все, у кого есть ссылка → Читатель».
> 4. Пришлите преподавателю ссылку на свою копию.

Без открытого доступа преподаватель не сможет посмотреть решение.

## Воспроизводимость

Для случайных выборок используйте фиксированный seed для воспроизводимости, например:

```python
import numpy as np
rng = np.random.default_rng(42)
```
